# Philly DJ Sets

A small static site that lists upcoming DJ sets in Philadelphia.

- Open `index.html` in a browser, or serve it with GitHub Pages (Settings → Pages → deploy from the `main` branch, root folder).
- Events live in `events.js`. Add an object to the list to add a set. Events whose date has passed are hidden automatically.
- Each event links to its ticket or listing page. Lineups and dates change, so confirm before going.
